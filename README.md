# Dino Game
The classic dinosaur game made with raspberry pi and Sense HAT. Added modifications and new features with inclusivity in mind. This is a course project.

#### Project name: Dino game
#### Course name: Advanced computer science in Sweden. [https://www.uu.se/en/study/course?query=1DT032]
#### Date completed: 23/10/2024

## Set it up
1. Set up your raspberry pi: [https://www.youtube.com/watch?v=CQtliTJ41ZE]
     - Make sure to remember your username, password, hostname, wifi name and wifi password. Take a picture!
2. Add the dino_game.py.
3. Add a cron to run the script on startup of the raspberrypi. Here is link to help with that: [https://www.youtube.com/watch?v=Gl9HS7-H0mI]

## Modifications:
1. No flying objects, all objects are 1 pixel.
2. There is a scoreboard, when you move down using the joystick. It shows the top 3 scores.
3. The game enters a colorblind mode when you move left.
4. You exit the application when you move right.
5. To play you move the joystick up.
6. The background changes depending on the weather (temperature and humidity).
